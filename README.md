# MoonC

MoonC 是一款本地 Markdown 编辑器：点进段落即可书写，离开后自动成稿，无需左右分屏。数据保存在你自己的电脑上。

官网：https://moonclearner.github.io/

## 功能

- **即时成稿**：当前段落可编辑，其余段落即时呈现效果；也可切换为全文编辑。
- **常用写法齐全**：标题、列表、任务、表格、代码、公式与流程图均可直接书写。
- **图片随手贴**：粘贴即可保存并插入，预览与原文同屏可见。
- **工作区与导出**：多标签、大纲、文件树；需要分享时可导出网页或 PDF。
